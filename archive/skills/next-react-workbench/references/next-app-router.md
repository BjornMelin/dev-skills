# Next App Router

Use this file when the task is page-, layout-, loading-, error-, or metadata-oriented.

Focus areas:

- route file conventions
- server/client boundaries
- async params and data patterns
- loading and error states
- route-level metadata
- forms and action flows

Default policy:

- use `next-best-practices` as the source of truth for Next-specific rules
- use browser verification after meaningful route changes
- keep Node runtime as the default unless the repo clearly requires another runtime
